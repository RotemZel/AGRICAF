Reading the figure

One panel per predictor. Each point is one explained year: across, the predictor’s own value that year, measured against the same month a year earlier; up, the Shapley value the model gave it. The line is a smooth fitted through those points.

Read the slope, not the level. Where the line is flat, the model’s response does not change with the size of the movement. Where it steepens, the response is non-linear: a small shortfall and a large one do not carry proportionate weight. Where the line crosses zero, the predictor stops pushing the forecast one way and begins pushing it the other.

Panels are ordered by Relative Intensity, and how many are shown is set on the left. Colour marks the forecast month.

A smooth drawn through few years is not evidence of a threshold. Read the shape as a description of the fitted model, not as an estimated response of the market.
